# ha-gym-tracker

Home Assistant custom integration for gym session tracking: total sessions, a day streak, and cost-per-session, all derived from a calendar of workout events — plus zone-based auto-detection that creates those calendar events for you.

**This integration is fully vibe coded** — written by an AI coding agent, not hand-written. It's been designed against a real Home Assistant instance's actual calendar/person/zone entities, but review the code yourself before trusting it with your own setup.

See `AGENTS.md` for architecture and setup.
